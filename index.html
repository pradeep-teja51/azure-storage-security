Azure Storage Security

Storage Account Firewall & Private Endpoint Lockdown

Project Overview

This project secures an Azure Storage Account by disabling public network access and allowing connectivity through an Azure Virtual Network and Private Endpoint.


The implementation uses Azure Virtual Network, Private Endpoint, Private DNS, Storage Firewall restrictions and Azure Policy.

Architecture

🖥️ Azure Test VM
↓
🌐 Virtual Network

🔎 Private DNS
↓
🔒 Private Endpoint
↓
☁️ Azure Storage Account

Execution & Security Tests

❌ Public Access Blocked

Test performed from an external Windows computer. 

curl -I --max-time 10 https://stazstoragepradeep01.blob.core.windows.net/test-data/test-security.txt

HTTP 403

Public/external access is rejected.

✅ Private DNS Resolution

Test performed from the Azure VM. 

nslookup stazstoragepradeep01.blob.core.windows.net

10.0.1.4

The Storage endpoint resolves to the Private Endpoint IP.

✅ Private Connectivity

HTTPS connectivity test performed from the Azure VM. 

curl -I --max-time 10 https://stazstoragepradeep01.blob.core.windows.net

HTTP 400

Azure Storage responded to the request, confirming service reachability through the private network path.
